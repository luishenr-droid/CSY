# Atualização para a versão 6.4

1. No GitHub, substitua `server.js` e `package.json` na raiz do repositório.
2. Faça o commit.
3. No Render, use **Manual Deploy → Clear build cache & deploy**.
4. Configure a confirmação de e-mail conforme `CONFIGURAR_EMAIL.md`.
5. Confirme em `/health` que a versão exibida é `6.4.0`.
