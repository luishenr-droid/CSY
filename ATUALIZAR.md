# Atualização NZN Quiz 6.8

## Alterações

- Botão global para alternar entre tema claro e escuro em todas as telas.
- Preferência de tema mantida no navegador.
- Pódio centralizado e redimensionado para caber na tela sem rolagem.
- Botão de retorno e resultado pessoal compactados para não cobrir o pódio.

## Publicação

1. Substitua `server.js` e `package.json` na raiz do repositório GitHub.
2. Faça o commit.
3. No Render, execute **Manual Deploy → Clear build cache & deploy**.
4. Confirme em `/health` que a versão é `6.8.0`.
